  # Open Developer Source

  ### Developers building open source platforms that anyone can self host and use.<br>Free, always.

  <br>

  <table><tr><td width="850" align="center">

  Good software keeps ending up behind subscriptions, locked into someone else's servers, or quietly shut down when the company pivots. We think the tools people rely on every day should belong to the people using them.

  So we build them in the open. Self host it yourself, or use our hosted version if you would rather not manage anything. Either way the core product stays free and the code stays yours.

  </td></tr></table>

## How we work

| | |
|---|---|
| **Open by default** | Discussions happen in public. Decisions are visible. If you want to know why something is the way it is, the conversation is there to read. |
| **No gatekeeping** | No resume screen, no interview, no minimum experience. If you want to build, there is room for you. |
| **Ship, then improve** | We would rather have something working and rough than something perfect and imaginary. |
| **The self hosted version is the real version** | Not a stripped down demo that pushes you toward a paid tier. |

<br>

## Who we want

| | |
|---|---|
| 💻 | Developers of any level who want real open source experience |
| 🧠 | People who know LLM applications, RAG or eval design |
| 🎨 | Designers, writers and testers, code is not the only contribution |

## Get involved

1. Pick a repo and read its README
2. Look through the open issues, or open one yourself
3. Come say hi in Discord: **[Join us](https://discord.gg/BntJK3Ff)**

## Why open source

Because self hosting means you are never held hostage by our pricing, our uptime or our decisions. Our hosted version has to earn its subscription by being genuinely more convenient, not by being the only option. That keeps us honest.
